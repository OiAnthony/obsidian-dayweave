# Journal-related excerpts

The official changelog describes these changes relevant to Journal product design:

- Markdown Mirror provides a read-only on-disk Markdown projection of DB graphs. Its example output separates `journals/2026_05_16.md` from `pages/*.md`.
- Keyboard shortcuts can create missing journal pages.
- Imported property values that reference custom-format journal pages are preserved.
- A database fix prevents `:block/name` from changing when the custom date formatter changes.
- `QuickCapture` gained a `prettify-url?` option.

The changelog states that Markdown Mirror updates as users edit, handles renames and path collisions, and remains opt-in per graph. Two-way synchronization was still listed as upcoming at the time of this post.
